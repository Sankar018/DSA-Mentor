# DSA Mentor 🧠

An AI-powered **Data Structures and Algorithms mentor** that helps beginners understand DSA concepts through interactive, conversational explanations.

## ✨ Features

* 🤖 AI-powered DSA assistance
* 💬 Conversational follow-up questions
* 📚 Beginner-friendly explanations
* 💡 Simple examples and explanations
* ⏱️ Time and space complexity when relevant
* 🎨 Interactive classroom-style web interface

## 🛠️ Tech Stack

* **Python**
* **Flask**
* **Google Gemini API**
* **HTML, CSS, JavaScript**

## 📁 Project Structure

```text
DSA-Mentor/
├── DSA.py
├── index.html
├── .env
├── .gitignore
└── README.md
```

## 🚀 Run Locally

```bash
pip install -r requirements.txt
python DSA.py
```

Add your Gemini API key to `.env`:

```env
GEMINI_API_KEY=your_api_key
```

Then open:

```text
http://localhost:5000
```

## 🎯 Purpose

Built as a learning project to explore **Generative AI, conversational AI, Flask, and Gemini API integration** while creating a practical DSA learning assistant.
